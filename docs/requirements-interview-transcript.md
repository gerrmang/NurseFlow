## 요약
병동 수간호사 또는 스케줄 관리자가 간호사 근무표를 작성한다. 현재 엑셀로 한 사람이 여러 간호사의 일정과 근무 규칙을 확인하느라 시간이 오래 걸린다. 간호사는 이미 승인된 휴가·반차를 관리자가 일정으로 등록할 수 있으며, 시스템은 이를 배치 불가 시간으로 취급한다. 규칙 기반 자동 배치로 월간 근무표 초안을 만들고, 관리자가 검토·수정·확정하면 해당 revision이 활성 달력에 공개 적용된다.

## 라운드별 핵심 답변
1. 관리자(수간호사 등)가 근무표를 편성하고 간호사들은 스케줄에 참여·조회한다. 데이/오프/나이트/휴가 같은 상황을 고려해 편성을 더 쉽고 효율적으로 한다.
2. 엑셀에서 혼자 여러 사람의 일정과 조건을 고려하느라 시간이 걸린다. 승인된 휴가/반차가 사전에 표시되고 달력에서 배치 가능 여부와 사유를 확인하고 싶다.
3. 정해진 규칙대로 자동 배치하는 AI 기반 기능도 필요하다.
4. 자동 생성된 표는 관리자가 검토·수정 후 확정하고 모두가 볼 수 있도록 공개한다.
5. 급여·근태 관리는 MVP에서 제외한다. 공식 휴가 승인 기능의 포함 여부를 확인한다.
6. 휴가·반차 신청/결재는 제외한다. 관리자가 이미 승인된 일정을 별도로 등록하고, 반차 시간대에는 배치할 수 없게 한다.
7. 자동 배치가 규칙을 임의로 어기지 않는다. 배치 불가 칸과 사유를 표시한다.
8. 필수 조건: 지정된 휴가 날짜, 반차 시간, 나이트 후 데이 휴식. 선호 조건: 균등 배분은 가능한 한 맞추고 실패하면 사유를 표시한다.
9. 가장 중요한 성공은 효율적인 편성과 월간 근무표 작성 시간 단축이다.
10. 현재 기준 시간은 모름. 목표는 기존 엑셀 대비 절반 이하로 줄이는 것이며, 파일럿에서 기준선을 측정한다.

## 압력 검증 및 결정
- 자동 배치 필요 여부를 명시적으로 확인했다. 자동 배치는 MVP에 포함된다.
- 결과물 공개 권한은 관리자에게 둔다. 자동 배치는 초안을 만들 뿐, 직접 게시하지 않는다.
- 휴가 승인/결재와 공식 HR 기록을 스케줄러가 수행하지 않는다. 이미 승인된 일정만 반영한다.
- 업무규칙의 hard/soft 구분을 확인했다: 휴가/반차/나이트 후 휴식은 hard, 균등 배분은 soft.
- 시간 목표는 “절반 이하”로 정의했지만 현재 기준 시간은 미측정이다. 파일럿에서 엑셀 기준선을 먼저 측정한다.

## 미확정 사항
- 병동별 인원 규모, 직군/숙련도 구성, 추가 근무 규칙과 법령 준수 검토
- 플랫폼과 배포 형태, 로그인/권한/병원별 데이터 분리
- 월간 편성 기준선을 측정할 파일럿 병동 및 평가 기간
- 간호사 스케줄 조회 외에 간호사가 직접 입력할 수 있는 기능 범위

## 인터뷰 종료 후 추가 결정
- 사용자는 제품을 앱으로 개발하고 Kotlin을 사용할 가능성이 높다고 밝혔다. 이를 Kotlin Android 클라이언트 선호로 계획에 반영하고, Android 타깃/서버/API/DB/배포는 P0 결정으로 남겼다.

## 후속 제품/API 결정
- 간호사는 병동 전체 달력과 본인 일정 보기를 선택할 수 있다.
- 미충원 칸이 있어도 관리자가 확인 후 확정할 수 있다. 확정된 revision만 활성 달력에 공개 적용되고, 그 전 초안은 달력에 반영되거나 간호사에게 보이지 않는다.
- API 계약은 안전성과 효율을 고려해 설계해 달라고 요청했다.
