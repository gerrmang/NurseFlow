## 변경 목적과 내용

Android 관리자가 팀·간호사·구성원을 기존 A5·A6 API로 관리한다. 병동 목록과 생성 후 설정 안내에서 진입한다.

- 팀 추가·이름·표시 순서·삭제, 간호사 기록 등록·수정·팀 배치
- 팀 내 드래그/버튼 경력순 정렬과 명시적 저장
- 실제 경력·직급 입력/확인, 선임·편성 단계와 조정 이력
- 구성원 관리자 지정/해제·접근 비활성/재활성

## 관련 이슈

없음 — breakdown B5a. 선행 A5·A6·B1 병합 완료.

## 권한·예외·인수 기준

서버가 최종 권한을 판정한다. 관리 화면은 진입·재조회 시 관리자 소속을 확인하고 권한 상실 시 관리 데이터를 폐기한다. 쓰기는 직렬화하고 응답 유실 시 자동 재전송하지 않는다. 최신 목록 재조회 실패 중 편집을 차단한다. 팀 정렬은 활성 팀원 전체를 보내며 TEAM_ORDER_STALE이면 다시 정렬한다. 일반 편집은 마지막 저장 우선이다.

인수: 팀 생성→간호사 등록/배치→순서 저장/재조회→실제 경력 확인→선임/단계 변경→이력 조회→구성원 권한 변경. 마지막 관리자·활성 기록 충돌·비활성 구성원·권한 상실·응답 유실을 검증한다.
