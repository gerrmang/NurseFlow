- 새 API·Store·DOM 회귀: 26개. 관리자 접근, 월·날짜·응답 검증, 전체 교체 본문, 빈 값/0분, 독립 입력 보존, 확인 취소, 400/412/503, 응답 유실·결과 확인, 늦은 응답 무시, 저장 직후 다른 revision으로 입력을 덮어쓰지 않는 경합 경로.

- 브라우저에서 가상 관리자 로그인→기존 근무 설정→휴일 화면→휴무일 저장→월 목표 147시간→140시간 갱신을 확인했다. 360px·1440px에서 문서 가로 폭과 내용 폭이 같았다. 서버·DB·계정은 검증용이며 실제 Kakao 인증이 아니다.
