# B6 실제 Kakao 웹 로그인 검증 (2026-11-20)

결과: **실제 Kakao 계정 1개의 웹 로그인·복원·로그아웃·재로그인 성공**. 가상 OIDC 결과와 구분한다. 두 실제 계정 전환·초대 가입, Android SDK의 이번 커밋 실로그인은 실행하지 않았다.

## 검증 환경과 비밀값 처리

- 검증 코드: `chore/demo-seed-script` HEAD `4d8590e`. backend는 dev `139b609` 이후 변경 없음(`git diff 139b609 HEAD -- backend` 비어 있음). 현재 bootJar와 현재 웹 소스로 실행했다.
- 서버: WSL JDK 21, 포트 8080, 새 `jdbc:h2:mem:b6_real_kakao`. 기존 사용자 H2 파일을 사용하지 않았다. 웹: Windows Node/Vite, `http://localhost:5173`, 서버 프록시 사용.
- 실제 인증 주소를 `https://kauth.kakao.com` issuer·JWKS·authorize·token 엔드포인트로 명시했다. 가상 인증 공급자·토큰 주입·API 가짜 응답은 사용하지 않았다.
- 사용자가 이전에 준비한 WSL Kakao 환경 파일을 출력 없이 source해 REST API 키·Client Secret을 전달했다. 서버 세션 서명 비밀값은 실행 시 무작위 생성했다. 키·토큰·인가 코드·쿠키·계정명·연락처는 보고와 Git에 기록하지 않았다.
- 브라우저: ChatGPT in-app browser. 기존 Kakao 로그인 상태에서 실제 인가 코드 왕복을 수행했다. 비밀번호 입력을 자동화하거나 새 계정을 만들지 않았다. Windows 네이티브 Whale 제어는 창 소유자 확인 오류가 반복돼 브라우저 전용 도구로 전환했다.
