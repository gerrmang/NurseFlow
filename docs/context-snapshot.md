# 프로젝트 컨텍스트 요약

이 문서는 인터뷰 전 초기 스냅샷을 최종 확인된 내용과 P0 미결정 항목으로 갱신한 요약입니다. 원래 deep-interview 기록은 `.omx/context/` 아래에 보존되어 있습니다.

## 프로젝트 상태
- NurseFlow 저장소에는 기존 앱 코드가 없는 Greenfield 프로젝트입니다.
- 제품: 병동 간호사 월간 근무표를 관리하고 자동 편성 초안을 만드는 앱.
- 주 사용자: 수간호사 또는 병동 스케줄 관리자. 간호사는 공개된 표를 조회합니다.

## 기술 방향
- 사용자 선호: Kotlin 기반 앱. 계획상 Android 네이티브 클라이언트를 우선 가정한다.
- Android 타깃 범위와 서버/API/DB·인증·동기화·호스팅은 미정이며 P0에서 정한다.

## 확정된 제품 경계
- 관리자가 이미 승인된 휴가/반차를 등록합니다. 휴가 신청·결재는 하지 않습니다.
- 자동 배치는 hard rule을 준수하는 비공개 초안을 만든다. 관리자가 검토·수정·확정하면 해당 revision이 공개되어 활성 달력에 적용된다.
- 지정 휴가, 반차 시간대, 나이트 후 데이 휴식은 반드시 지킵니다. 균등 배분은 가능한 한 맞추고 이유를 설명합니다.
- 급여·근태·공식 HR 대체는 제외합니다.
- 목표: 월간 전체 편성시간을 비교 가능한 엑셀 작업시간의 절반 이하로 줄입니다. 기존 기준선은 파일럿에서 측정합니다.

## P0에서 결정할 사항
병동/인원 규모, 근무시간과 월 경계, 필요 인원/자격조건, 정확한 휴식규칙, fairness 산식, 고정 배치/재생성 정책, 미충원 근무의 확인 표시/감사기록 형식, Android 타깃/인증/서버/API/DB/호스팅/보존, 최대 규모와 SLO, 엑셀 연동, 파일럿 측정표본.
